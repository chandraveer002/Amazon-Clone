# 🛒 Amazon Clone (HTML & CSS)

A static Amazon clone built using **only HTML and CSS**. This project replicates the look and feel of Amazon's homepage with a responsive design.

## 🌟 Features

- 📱 Fully responsive layout  
- 🎨 Modern UI with CSS styling  
- 🏷️ Header, Banner, Product Listings, and Footer  
- 🖼️ Hover effects and clean design
